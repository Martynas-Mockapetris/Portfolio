## Getting Started

To run the portfolio locally:

### 1. Clone the repository

```bash
git clone https://github.com/Martynas-Mockapetris/Portfolio.git
cd Portfolio
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Vite will provide a local URL in the terminal where you can preview the website.

### 4. Build for production

```bash
npm run build
```

The production-ready files will be generated in the `dist/` directory.
